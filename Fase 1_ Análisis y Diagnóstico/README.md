# Documentación de análisis

Esta fase conserva dos documentos aprobados en versiones distintas:

- [Informe de análisis y diagnóstico aprobado v1.0.pdf](Informe%20de%20an%C3%A1lisis%20y%20diagn%C3%B3stico%20aprobado%20v1.0.pdf): línea base de requisitos aprobada para iniciar Diseño.
- [Diccionario de Datos y Mapeo Legacy v1.1 - SGMA.pdf](Diccionario%20de%20Datos%20y%20Mapeo%20Legacy%20v1.1%20-%20SGMA.pdf): diccionario y mapeo actualizados para v1.1.
- [Entrevista y encuesta de requisitos SGMA.docx](Entrevista%20y%20encuesta%20de%20requisitos%20SGMA.docx): material de relevamiento.

El SRS v1.1 aprobado no está disponible en los archivos locales revisados. Por decisión del equipo, el informe v1.0 queda como referencia para los requisitos que contiene; no se deben atribuirle requisitos que no figuren allí.
